# Gnome Tasks

A habit-tracking game where real-life chores grow an island village.
Complete daily tasks, tend your garden, chop wood, defend the town.

Built with Python + Pygame-CE.

## Setup

    python -m venv .venv
    # Windows:
    .venv\Scripts\activate
    # macOS / Linux:
    source .venv/bin/activate

    pip install -r requirements.txt

## Run

    python main.py
